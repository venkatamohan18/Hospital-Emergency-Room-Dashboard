# 🏥 Hospital Emergency Room Dashboard | Power BI

## 📌 Project Overview
This project presents an interactive Hospital Emergency Room Dashboard developed using Microsoft Power BI. It helps analyze patient visits, admission patterns, waiting times, and emergency department operations through key performance indicators (KPIs) and visualizations.

## 🎯 Project Objectives
- Analyze patient visits and admission patterns.
- Monitor patient waiting times and satisfaction metrics, where available.
- Identify trends in patient arrivals by date and time.
- Explore patient demographics and department referrals.
- Support data-driven decision-making for hospital operations.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPIs.
- **Data Modeling** – Organizing data for analysis.
- **Microsoft Excel** – Source data preparation, if applicable.

## 📊 Key Performance Indicators
Depending on the dataset, the dashboard may include:
- Total Patients
- Average Waiting Time
- Patient Satisfaction Score
- Patient Admission Rate
- Patient Visits by Date and Time
- Patient Distribution by Age Group and Gender
- Department Referral Analysis

## 📈 Dashboard Features
- KPI cards for key operational metrics.
- Patient admission and non-admission analysis.
- Waiting time and patient satisfaction analysis.
- Patient demographic visualizations.
- Patient visit trends.
- Interactive filters and slicers, where implemented.
